# Data Science Notes
This repository is where I collect various projects: experiments, intuition-building notebooks, a machine learning "curiosity corner”, etc.

It's **very much under construction** and intentionally informal $—$ a place for interesting ideas and small demonstrations rather than big, polished portfolio projects.

---

### In [open-data-analysis](https://github.com/greeny-blue/data-science-notes/tree/main/open-data-analysis) you'll find:

  - Odd bits of analysis pertaining to the Russian Invasion of Ukraine using data from [Ragnar Gudmundsson's Ukraine Dashboard](https://lookerstudio.google.com/reporting/dfbcec47-7b01-400e-ab21-de8eb98c8f3a/page/p_70wiatllvd?s=up65eAX-um4).
    - [A Brief Exploratory Analysis of Reported Russian Casualties and Vehicle Losses](https://github.com/greeny-blue/data-science-notes/blob/main/open-data-analysis/russian-invasion-of-ukraine/personnel-and-vehicle-losses/Russian-personnel-and-vehicle-losses.md). This analysis was inspired by Ukraine and geopolitics analyst Professor Darin Gerdes. Turning it around and sending that evening he featured some of this analysis on the next show on his [YouTube channel](https://www.youtube.com/@Professor-Gerdes) (5th March 2026).
    - [Russian Army Size Projections Based on Recruitment Scenarios](https://github.com/greeny-blue/data-science-notes/blob/main/open-data-analysis/russian_army_size_projections/Russian-army-size-change-projections.md). A simple projection of Russian army size based on reported casualty rates since December 2025 and a range of assumed recruitment levels. This was prompted by a recent claim by Jason Jay Smart that recruitment may have fallen to ~800 per day, and explores what that might imply for force size over time.
